# Определение тематики обращения с помощью ИИ

Проект классификатора текстовых обращений клиентов онлайн-банка по 5 ключевым темам.

## Описание датасета
* **Название:** `course_project_text_dataset`
* **Источник:** Синтетическая генерация через **Claude Sonnet 4.6 (Anthropic)**.
* **Автор:** bullymichael
* **Формат:** CSV (кодировка `UTF-8`)

### Категории (Классы):
1. `Вклады_и_инвестиции` (депозиты, акции, проценты, накопительные счета)
2. `Кредиты_и_ипотеки` (заявки на кредит, ипотека, графики платежей, долги)
3. `Качество_товара_или_услуги` (претензии, брак, несоответствие описанию, жалобы)
4. `Гейминг_и_донат` (внутриигровая валюта, пинг, читеры, проблемы со входом)
5. `Сотрудничество_и_реклама` (коммерческие предложения, вакансии, PR-контакты)

## Права и конфиденциальность
* **Правовой статус:** Датасет полностью синтетический. По соглашению Anthropic права принадлежат пользователю. Распространяется под лицензией **MIT**.
* **Конфиденциальность:** Разработан по принципу **Privacy-by-Design**. Не содержит реальных персональных данных (PII) и банковской тайны. Соответствует 152-ФЗ. Все данные маскированы (*«карта *1234»*, *«Иван И.»*).

## 🚀 Структура файлов
* `course_project_text_dataset` — исходная папка
* `data` — папка с csv файлами
* `README.md` — информация о датасете
* `train.csv` — датасет для обучения
* `test.csv` — датасет для проверки
